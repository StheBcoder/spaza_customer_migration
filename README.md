# Spaza to L'Oreal - Customer Migration Journey

This project visualizes how customers move from Spaza shop awareness to L'Oreal purchase and advocacy.

## The Funnel
- **Awareness:** 850 customers discovered via Spaza
- **Consideration:** 520 showed interest
- **Purchase:** 310 bought L'Oreal
- **Advocacy:** 120 became repeat advocates

## Charts
1. `chart_1_journey.png` - Line chart showing customer drop-off across stages
2. `chart_2_bars.png` - Bar comparison of each stage
3. `chart_3_pie.png` - Share of customers at each stage

## Key Insight
Biggest drop is from Awareness to Consideration (38% loss). Opportunity to improve in-store education and sampling at Spaza level to keep customers.
